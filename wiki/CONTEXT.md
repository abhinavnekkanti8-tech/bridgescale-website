# How to Use This Wiki

## Navigation

1. **Start with [INDEX.md](INDEX.md)** — lists all 12 topics and 3 concepts with one-line summaries
2. **Read a topic article** before reading raw source files. Each article synthesizes 10–20 source files into a single briefing with sections: Purpose, Architecture, Talks To, API Surface, Data, Key Decisions, Gotchas
3. **Use concepts** for cross-cutting questions that span multiple modules

## When to read raw sources vs. wiki

| Situation | Use |
|-----------|-----|
| Understanding how a module works | Wiki topic article |
| Cross-module patterns (auth, payments, AI) | Wiki concept article |
| Finding a specific function signature | Raw source file |
| Debugging a specific bug | Raw source file (wiki points you there in Sources section) |
| Adding a new feature | Wiki first for context, raw source for implementation |

## Keeping the wiki fresh

Run `/wiki-compile` after:
- Adding or renaming modules
- Significant changes to the Prisma schema
- New API endpoints
- Frontend route restructuring
- Completing Phase 2 TODO items (BlurredMatchCard, CompletionChecklist, etc.)

Run `/wiki-ingest path/to/new-file.md` for a single new doc.

## Wiki files are read-only

Never modify files in `wiki/` directly — they are regenerated by `/wiki-compile`. Source of truth is always the actual source code and `Docs/`.
